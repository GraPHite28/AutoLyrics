# AutoLyrics

Мягкое цветное окно для Windows, которое само подхватывает музыку на ПК, показывает
синхронизированный текст песни и рисует визуализатор под жанр. Интерфейс скрыт —
меню открывается правым кликом.

Языки интерфейса: русский, English, Deutsch, Français, Polski, 中文, 日本語.

## Как это работает

- **Трек.** Если плеер сообщает трек Windows (Яндекс Музыка, Spotify, Chrome/Edge, VLC…),
  берём его оттуда. Если нет (например, веб-плеер в Яндекс Браузере) — слушаем звук с ПК и
  определяем песню по отпечатку (алгоритм Shazam), смещение внутри трека даёт синхронизацию.
- **Текст.** LRCLIB, NetEase, QQ Music, KuGou (синхронизированный) и lyrics.ovh (обычный)
  опрашиваются параллельно, результат берётся по приоритету. Найденное сохраняется в папку
  `lyrics` как обычные `.lrc` — туда же можно класть свои файлы `Артист - Название.lrc`.
  Необязательно: ключ Musixmatch в меню.
- **Визуализатор.** Спектр, удар и темп считаются из звука; стиль выбирается по жанру
  (Shazam / iTunes), а если жанр неизвестен — по самому звуку. Семь стилей, переключение плавное.
- **Первый запуск.** Приветствие на всех языках просит включить любимую песню на родном языке,
  язык определяется по найденному тексту. Язык всегда можно сменить в меню.

## Управление

| Действие | Как |
|---|---|
| Меню и все настройки | правая кнопка мыши |
| Перетащить окно | левая кнопка мыши |
| Полный экран | двойной клик |
| Свернуть в трей / вернуть | пункт «В трей» / клик по значку в трее |

В меню: выбор варианта песни, «Определить сейчас», размер и сдвиг текста, визуализатор,
анимации, Musixmatch, автозапуск с Windows, угадывание следующего трека альбома (по умолчанию
выключено), язык, Liquid Glass.

## Установка

Готовый установщик (NSIS, без прав администратора, с выбором языка установки):
`src-tauri/target/release/bundle/nsis/AutoLyrics_<версия>_x64-setup.exe`.

## Сборка из исходников

Нужны Rust (MSVC-тулчейн, Visual Studio Build Tools) и WebView2 (есть в Windows 11).
Node.js не нужен — интерфейс написан на чистом JavaScript без сборщика.

```powershell
cd src-tauri
cargo run                 # запуск в режиме разработки
cargo test                # тесты
cargo install tauri-cli --version "^2" --locked
cargo tauri build         # release-сборка и установщик
```

Отладка: переменная `AUTOLYRICS_DEBUG=1` печатает работу распознавания и поиска текстов.
Интерфейс можно посмотреть и в обычном браузере, отдав папку `src` любым статическим сервером
(демо-режим): параметры `?viz=rock`, `?lang=de`, `?ob=1`, `?lyrics=de`.

## Что уходит в интернет

Запросы текстов и жанров (названия и артисты) к LRCLIB, NetEase, QQ Music, KuGou, lyrics.ovh,
iTunes; отпечаток звука (несколько секунд, не сама запись) — к Shazam; обложки — по ссылкам из
ответов. Если указан ключ Musixmatch — запросы к его API. Кнопка «Поддержать проект» (если вы вписали ссылку в `src/config.js`) открывает ссылку обмена Steam. Сама запись звука не сохраняется и не
отправляется. Сервис Shazam используется неофициально и может измениться.

## Структура

```
src/                 интерфейс (HTML/CSS/JS): фон, визуализатор, заставка, меню, i18n
src-tauri/src/       Rust: media_watcher (SMTC), audio_capture (WASAPI loopback), analyzer (FFT),
                     recognizer (Shazam), lyrics/ (источники, .lrc-папка), genre, album, predict, shell
PLAN.md              план и статус этапов
```
